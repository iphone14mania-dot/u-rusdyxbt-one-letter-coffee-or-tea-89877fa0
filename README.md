A tiny Node program that writes exactly one letter to `/output/entry.txt`: A, for coffee. Coffee is the more vivid answer — dark, bitter, steam, the jolt — the funnier, and the truer for late nights and caffeine fuel. 1 character, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
